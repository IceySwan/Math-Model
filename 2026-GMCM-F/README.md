# 2026 年研究生数学建模竞赛 F 题

算力约束下提升大语言模型能力的资源配置建模。

本目录整理了题目、正式代码与当前论文，适合作为 GitHub 仓库根目录提交。

| 目录 | 内容 |
| --- | --- |
| `problem/` | 原始题目 DOCX、Markdown 题面、附件编号与字段说明 |
| `code/` | 48 个 Python 源文件、2 个算法配置、依赖清单与运行说明 |
| `paper/` | 当前论文 PDF、LaTeX 源码、模板、参考文献和编译所需图表 |

论文正文中引用的图表属于论文组成部分，保存在 `paper/figures/` 与 `paper/tables/`。

原始附件、独立运行结果、派生数据、缓存、日志、历史版本和审查报告均已排除。`.gitignore` 按发布文件类型设置白名单，覆盖本地数据与编译中间文件。

## 阅读与运行

- 阅读题目：[题面](problem/F-problem.md)、[附件说明](problem/F-data.md)。
- 阅读论文：[PDF](paper/main.pdf)。
- 源码与运行依赖：[代码说明](code/README.md)。
- 论文编译：[编译说明](paper/README.md)。

算法运行需要另行准备赛题附件。Q2 当前入口还使用两项本地辅助结果，具体路径见代码说明。论文使用随仓库保存的图表即可编译。

## 提交

将本目录中的 `problem/`、`code/`、`paper/`、`README.md` 和 `.gitignore` 一起上传到 GitHub 仓库根目录。
